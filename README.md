# Web Scraper for Headlines & Quotes

A simple and clean Python web scraper using `requests` and `BeautifulSoup` to extract quotes/headlines and save them into a JSON file.

## Requirements
- Python 3.x

## Installation & Usage
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the scraper:
   ```bash
   python scraper.py
   ```
